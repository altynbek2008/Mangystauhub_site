# Mangystau Hub Bot — README

## Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
git clone <repo-url>
cd tg_bot
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Создание файла `.env`

Скопируйте `.env.example` и заполните своими данными:

```bash
cp .env.example .env
```

Откройте `.env` и укажите:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | Telegram ID администраторов (через запятую) |
| `AI_PROVIDER` | `gemini` (по умолчанию) или `openai` |
| `GEMINI_API_KEY` | Ключ Google Gemini с [aistudio.google.com](https://aistudio.google.com) — **бесплатно** |
| `OPENAI_API_KEY` | Ключ OpenAI (опционально) |

> **Как узнать свой Telegram ID?** Напишите боту [@userinfobot](https://t.me/userinfobot).

### 3. Заполнение базы знаний

Отредактируйте файл `knowledge_base.md`. Структура файла:

```
## О хабе          — описание, миссия, направления работы
## Контакты        — адрес, телефон, email, соцсети, режим работы
## Мероприятия     — таблица с датами, временем и названиями событий
## Услуги хаба     — коворкинг, менторство, акселерация
## FAQ             — часто задаваемые вопросы
```

**Формат таблицы мероприятий:**

```markdown
| Дата   | Время | Мероприятие        | Место         |
|--------|-------|--------------------|---------------|
| 15 ноя | 10:00 | Воркшоп по Python  | Учебный класс |
```

> **Совет:** Бот всегда знает текущую дату, поэтому он корректно ответит на вопросы «на этой неделе», «на следующей неделе» и т.д.

### 4. Запуск Telegram-бота

```bash
python main.py
```

### 5. Запуск веб-сайта (Flask)

```bash
python app.py
```
После запуска откройте в браузере: `http://localhost:5000`

## Горячая перезагрузка базы знаний

После обновления `knowledge_base.md` не нужно перезапускать бота.  
Напишите боту команду:

```
/reload_kb
```

> Команда доступна только администраторам, чьи ID указаны в `ADMIN_IDS`.

## Получение бесплатного ключа Gemini

1. Перейдите на [aistudio.google.com](https://aistudio.google.com)
2. Войдите через Google-аккаунт
3. Нажмите **Get API key** → **Create API key**
4. Скопируйте ключ в `.env` как `GEMINI_API_KEY`

Бесплатный тариф: **15 запросов в минуту**, **1 500 запросов в сутки** для `gemini-1.5-flash`.

## Конфиденциальность

Бот **не собирает и не хранит** персональные данные пользователей.  
История диалога хранится только в оперативной памяти в рамках одной сессии (FSM) и очищается при перезапуске или выходе из режима ИИ.
